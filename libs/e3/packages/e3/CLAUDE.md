# e3 (SDK)

TypeScript SDK for authoring e3 packages: `e3.input`, `e3.task`,
`e3.package`, `e3.export`, `e3.ui`. The user-facing surface for
declaring inputs, tasks, dataflows, and UI within an e3 package.
