# east-c-std

> Standard platform functions for east-c — console, fs, path, crypto, time, random, fetch, test

[![License](https://img.shields.io/badge/license-BUSL--1.1-orange.svg)](LICENSE.md)

**east-c-std** provides the standard set of platform functions for the C runtime. It mirrors the API of [`@elaraai/east-node-std`](../../../east-node/packages/east-node-std) so East programs are portable between Node.js and the native C runtime.

## Modules

- **Console** — `log`, `warn`, `error`
- **FileSystem** — `readFile`, `writeFile`, `exists`, `listDir`
- **Path** — `join`, `dirname`, `basename`, `extname`
- **Crypto** — `uuid`, `random`, `sha256`
- **Time** — `now`, `add`, `diff`, `format`
- **Random** — `next`, `between`, distributions
- **Fetch** — HTTP GET / POST (libcurl-backed)
- **Test** — `testPass`, `testFail` (compliance harness)

## Build

```bash
make build    # From libs/east-c/
make test
```

See [`docs/conventions/MAKEFILE_TARGETS.md`](../../../../docs/conventions/MAKEFILE_TARGETS.md).

## Compliance

`east-c-std` runs the same compliance test suite as `east-node-std`. IR files are exported from the TypeScript side:

```bash
# From workspace root
make test-export
# From libs/east-c
make compliance-std
```

## Claude Code plugin

The East ecosystem also ships a [Claude Code](https://claude.com/claude-code) plugin — East language skills, example search, and preemptive diagnostics for East code — installed separately from the `elaraai` marketplace:


```bash

```
