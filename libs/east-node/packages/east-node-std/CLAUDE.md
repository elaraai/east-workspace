# East Node Std

Node.js standard platform functions for the East language: `Console`,
`FileSystem`, `Fetch`, `Crypto`, `Time`, `Path`, `Random`,
and the test framework (`describeEast`, `Assert`, `Test`).

The `NodePlatform` export bundles all implementations for use via
`platformFns:` in `describeEast` blocks or `East.compile()`.
