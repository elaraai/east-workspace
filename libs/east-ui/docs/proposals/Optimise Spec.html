Optimise

The eye sends the period in view to the optimiser as one RPC, an e3 function call, which takes 5–10 s. While it runs, the eye pulses cyan and the footer counts the seconds; hovering the eye stops it. The result lands in one commit as an edit, the same as a manual one: Undo, Redo, Cancel and Apply in the edit bar handle it. As it lands, every new or changed entry flares cyan in reading order and keeps a cyan glow, and an alert under the toolbar says what changed. After a few seconds the alert and the glow go, and the changes stay as unapplied edits. Each builder shows an empty period and one with entries, in light and dark; the controls switch the ideas on every card.
