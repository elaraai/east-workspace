east · studio — concept exploration

Component libraries, page libraries,
and the layouts that combine them

Developers publish a fixed catalog of pre-configured east-ui components — a specific Trend chart, a wired Assignment Board, a KPI rail. Operators browse that Component Library and a Page Library (templates + live instances), then compose them onto a snap grid of rows and columns. No code — the configuration is locked at publish time; operators arrange, bind, and publish.
