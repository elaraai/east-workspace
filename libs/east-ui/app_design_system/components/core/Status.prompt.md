The one legal way to show status in East: dot + uppercase mono word. Tinted badge backgrounds are banned.

```jsx
<Status level="ok">Committed</Status>
<Status level="warn">Pending</Status>
<Status level="error">Blocked</Status>
<Status level="live">Live</Status>
<Status level="ring">Not started</Status>
```

`live`/`run` pulse for in-flight processes; `ring` is a hollow dot for not-yet states.
