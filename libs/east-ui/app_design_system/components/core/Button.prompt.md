Standard East action button; use for every clickable action — never restyle one ad hoc.

```jsx
<Button variant="primary">Apply</Button>
<Button>Discard</Button>
<Button variant="ghost" compact>Edit</Button>
<Button variant="commit">Commit changes</Button>
```

Variants: `default` (bordered paper), `primary` (brand-d fill, one per surface), `ghost` (chrome-free), `danger` (neg text), `commit` (mono uppercase — reserved for commit-bar actions). `compact` for toolbars/rows.
