Mono pill for numeric change, always tabular JetBrains Mono.

```jsx
<DeltaPill dir="up">+4.2%</DeltaPill>
<DeltaPill dir="down">−$18k</DeltaPill>
<DeltaPill dir="flat">0</DeltaPill>
<DeltaPill dir="up" outlined>+12</DeltaPill>
```

`up` is positive-good only — if up is bad (cost, risk) use `dir="down"` coloring semantics by valence, not direction. `outlined` for diff/compare surfaces.
