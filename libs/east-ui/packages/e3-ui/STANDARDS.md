# East UI Development Standards

e3-ui follows the **same development standards as `@elaraai/east-ui`** —
TypeDoc documentation rules, TypeDoc example validation, testing standards,
and the compliance checklist are identical.

**Canonical source:** [`../east-ui/STANDARDS.md`](../east-ui/STANDARDS.md)

Refer to that document for all standards. This pointer exists so the
duplicate is not maintained in two places (the two files had previously
drifted). Any e3-ui-specific addition should be made in the canonical file
under a clearly labelled e3-ui section, not forked here.
