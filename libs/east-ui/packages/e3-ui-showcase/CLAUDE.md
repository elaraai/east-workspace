# e3-ui-showcase

Showcase and development app for e3-ui components (the e3-specific
renderers — `DataTaskPreview`, `TaskPreview`, `EastValueViewer`, etc.).

Mirrors `east-ui-showcase`'s role: hosts the runtime demo and runs the
snapshot pipeline for the e3-specific UI surface.
