§2.4 Compare

Compare-mode patterns answer "what changed?" or "A vs B?". Every commit-adjacent surface here is patch-typed: DiffView renders directly from a Patch<T>, and deltas carry magnitude + significance + confidence so users don't act on noise.

DeltaPill ContextSelector VersusHeader DiffView

2.4.1DeltaPill

Inline directional-delta chip. magnitude flips direction-to-colour mapping for non-monotonic KPIs; optional CI decoration and significance asterisk so callers don't infer noise as signal.

2.4.2ContextSelector

Labelled chip that opens a rich picker. Used at the top of a region to switch the scenario, period, region, or entity the surface beneath is scoped to. Items carry an optional description + tag so the picker shows more than just a label.

ContextSelector.Root({ label, value: UIComp, items: Array<{ value, label: UIComp, description? }>, onChange })
closed (default) Inline chip in a header or toolbar
size: sm Tighter for dense toolbars
open Filter input + items with description + tag

2.4.3VersusHeader

A vs B with hot-swap menus and a delta slot. Sits at the top of a Compare view. Each side carries an accent stripe so the colour mapping flows down into the rest of the surface (charts, tables, diffs).

2.4.4DiffView

Structured-object comparison rendered directly from a Patch<T>. Works for any East type: structs, arrays, dicts, variants, nested shapes — the patch structure drives the render. Supplies one of after or patch; the renderer resolves the other via East.diff / East.applyPatch.
