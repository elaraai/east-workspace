§2.1 Observe

Observe-mode patterns answer "what's happening?" — KPI tiles, segment breakdowns, anomaly lists, timeline projections, and the friction-free entry points for a user landing on a page. Surfaces stay airy and number-led; status colour is always paired with an icon (§0.3).

StatCard StatGrid MetricRail ListDetailLayout LegendRail FilterBar SearchResultsSummary ThresholdBand Provenance.Stamp ForecastView ProjectionToTarget SegmentedView AttentionList PartialResultsNotice FirstRunState
