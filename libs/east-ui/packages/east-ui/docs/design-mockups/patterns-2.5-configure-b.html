2.5.9AssignmentBoard

Generic drag-to-assign grid. Items in a tray drop onto cells of a grid (worker → shift, order → truck, lead → owner). Each drop emits a Patch<TBoard>; the parent composes drops into a draft until commit. validateDrop shows valid / invalid drop targets in flight. Drag-and-drop pairs with the required DnD.KeyboardMove fallback (§0.2).

2.5.12ConflictAnnotator — recipe

Not a pattern: a recipe over Status + Tooltip applied per offending cell of any grid (Matrix / Planner / AssignmentBoard). Iterate the grid's cells, attach a status chip when a conflict applies, surface the rule in a tooltip on hover.

Recipe — for each cell with a conflict, render Status({ tone: warn|err, label }) + Tooltip({ children: ruleExplanation })
canonical 5×3 mini-grid showing pass · warn · fail annotations
★ Recipe convention. Every offending cell renders a Status chip in its corner. The chip's tone (ok | warn | err) maps the rule's severity. Hovering surfaces a Tooltip with rule label + violation detail. Use this on Planner cells, Matrix cells, AssignmentBoard cells — any grid with cell addressability.
