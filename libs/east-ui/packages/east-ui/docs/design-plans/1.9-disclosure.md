# 1.9 — Disclosure (`Accordion`, `Tabs`, `Carousel`, + new `SegmentGroup`, `Collapsible`, `Disclosure`, `Steps`, `Timeline`, `OptionList`)

**Gaps-doc reference:** [`COMPONENT_AND_PATTERN_GAPS.md` §1.9](../COMPONENT_AND_PATTERN_GAPS.md).
**Scope:** Promote `Accordion.item.trigger` and `Tabs.item.trigger` to `UIComponentType`; add colour escape hatches on existing three; add `SegmentGroup`, `Collapsible`, `Disclosure` (text-truncation), `Steps`, `Timeline`. Add `OptionList` shared primitive (used under `AlternativesList` / `WhatIfList`). Apply the Type-shape convention (README §Type-shape convention, 0-conventions §3.8): content (`items` / `trigger` / `content` / `options`) + state (`value` / `defaultValue` / `activeIndex` / `selectedId` / `index`) + config (`multiple` / `collapsible` / `loop` / `autoplay` / `slidesPerView` / `slidesPerMove` / `allowMouseDrag` / `showIndicators` / `showControls` / `spacing` / `padding` / `lines` / `moreLabel` / `lessLabel` / `defaultOpen`) + behaviour (`onChange` / `onValueChange` / `onOpenChange` / `onIndexChange` / `onSelect`) on main. Visual presets (`variant` / `size` / `colorPalette`) + geometric (`orientation`) + colour slots in `style: OptionType(XxxStyleType)`. **Shipped `AccordionStyleType` holds `multiple` / `collapsible` / `onValueChange` today — this plan moves them OUT to main.**
**Out of scope:** none (this is a primitive-only plan).

## 3. Per-entry design

### 3.1 `Accordion` — rich trigger + main/style split

Shipped `AccordionStyleType` has `multiple` / `collapsible` / `variant` / `onValueChange`. `multiple` + `collapsible` are config (wiring flags) and `onValueChange` is behaviour — these move OUT to main. `variant` stays in style.

```ts
export const AccordionItemType = StructType({
    value: StringType,
    trigger: UIComponentType,                      // was StringType — string coerced at factory
    content: ArrayType(node),
    disabled: OptionType(BooleanType),
});

export const AccordionStyleType = StructType({
    variant: OptionType(AccordionVariantType),     // visual preset
    size: OptionType(SizeType),
    // Colour slots
    background: OptionType(StringType),
    borderColor: OptionType(StringType),
    triggerBackground: OptionType(StringType),
    triggerHoverBackground: OptionType(StringType),
    contentBackground: OptionType(StringType),
});

// Inline in component.ts:
Accordion: StructType({
    // Content
    items: ArrayType(AccordionItemType),
    // Config
    multiple: OptionType(BooleanType),
    collapsible: OptionType(BooleanType),
    // State
    value: OptionType(ArrayType(StringType)),
    defaultValue: OptionType(ArrayType(StringType)),
    // Behaviour
    onValueChange: OptionType(FunctionType([ArrayType(StringType)], NullType)),
    // Visual
    style: OptionType(AccordionStyleType),
}),
```

Factory coerces `trigger: string` → `Text.Root(s)`. Unlocks grid-aligned accordion headers (the area-block row in shift-optimiser lines ~1322–1341).

**Migration:** call sites passing `style: { multiple: true, collapsible: true, onValueChange: ... }` move these fields to the top-level options object.

**Example:** `accordionGridTrigger` — each accordion trigger is a Grid with `24px 1.2fr 100px 100px 140px 100px` columns, mirroring `shift-optimiser-mockup.html` lines ~1322–1342 (Red Vintage area block). Keep structure only; theme owns values.

### 3.2 `Tabs` — rich trigger

Identical change. Enables count badges and two-line labels (shift-optimiser `Week 12 / Vintage · 17–23 Mar` — lines ~1295–1304).

**Examples added:**
- `tabsWithCountBadges` — outer `Inputs / Results 5` where `5` is a Badge.
- `tabsTwoLine` — `Week 06 / Vintage · 3–9 Feb` trigger.

### 3.3 `Carousel`

Main carries content + state + config (items, index/defaultIndex, loop/autoplay/slidesPerView/slidesPerMove/allowMouseDrag/showIndicators/showControls/spacing/padding + `onIndexChange`). Visual presets (`orientation`) + colour slots in style.

```ts
export const CarouselStyleType = StructType({
    orientation: OptionType(OrientationType),
    // Colour slots
    indicatorColor: OptionType(StringType),
    activeIndicatorColor: OptionType(StringType),
    controlColor: OptionType(StringType),
    controlBackground: OptionType(StringType),
});
```

Shipped `CarouselStyleType` likely holds `orientation` already (visual) — fine. Main type keeps items / index / defaultIndex / loop / autoplay / slidesPerView / slidesPerMove / allowMouseDrag / showIndicators / showControls / spacing / padding / onIndexChange.

### 3.6 `Disclosure` / `ShowMore` (new)

Text-truncation primitive. Distinct from `Collapsible` (open/close arbitrary region).

```ts
export const DisclosureType = StructType({
    text: UIComponentType,       // typically a Text.Root
    lines: OptionType(IntegerType),   // default 3
    moreLabel: OptionType(StringType),  // default "show more"
    lessLabel: OptionType(StringType),  // default "show less"
    style: OptionType(DisclosureStyleType),
});

export const DisclosureStyleType = StructType({
    color: OptionType(StringType),
    triggerColor: OptionType(StringType),
});
```

**Renderer:** CSS line-clamp + a "show more / show less" link toggle. Used by `ActionCard.rationale`, `DriverList` narratives.
