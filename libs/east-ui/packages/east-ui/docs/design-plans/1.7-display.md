# 1.7 — Display (`Badge`, `Tag`, `Avatar`, `Stat`, `Icon`, + new `MetricChip`, `EditableChip`, `Kbd`, `Meter`, `SegmentedMeter`, `BarStrip`, `AvatarGroup`)

**Gaps-doc reference:** [`COMPONENT_AND_PATTERN_GAPS.md` §1.7](../COMPONENT_AND_PATTERN_GAPS.md).
**Scope:** Apply the Type-shape convention (README §Type-shape convention, 0-conventions §3.8) to every display primitive — content / state / behaviour on main, every visual field inside a `style: OptionType(XxxStyleType)` sub-struct. Widen `Stat`/`Avatar` with escape hatches; restructure `Stat.indicator` to orthogonal direction + sentiment; add six new primitives — `MetricChip`, `EditableChip`, `Kbd`, `Meter`, `SegmentedMeter`, `BarStrip`; add optional `AvatarGroup`; **retire** `src/charts/bar-segment/` and `src/charts/bar-list/` in favour of the new inline display primitives. Icon keeps Font Awesome-only per gaps doc §1.7. **Also: migrate shipped `Badge` / `Tag` / `Avatar` from their current flat shape to the main/style split** — their many visual fields (variant, colorPalette, size, color, background, borderColor, borderRadius, border*, overflow*, width/height/min*/max*, padding, margin, opacity, closable-side styling) move INTO `XxxStyleType`. `closable` + `onClose` on `Tag` stay on main (state + behaviour).
**Out of scope:** custom-SVG icon (deferred). Chart-level bar charts (§1.11 plan).

## 3. Per-entry design

### 3.1 `Stat` — restructure `indicator`

```ts
export const StatDirectionType = VariantType({ up: NullType, down: NullType, flat: NullType });
export const StatSentimentType = VariantType({ positive: NullType, negative: NullType, neutral: NullType });

export const StatIndicatorType = StructType({
    direction: StatDirectionType,
    sentiment: OptionType(StatSentimentType),
    icon: OptionType(IconType),
});

export const StatStyleType = StructType({
    size: OptionType(SizeType),
    // Colour slots
    valueColor: OptionType(StringType),
    labelColor: OptionType(StringType),
    helpTextColor: OptionType(StringType),
    indicatorColor: OptionType(StringType),
});

// Stat in component.ts:
Stat: StructType({
    // Content
    label: StringType,
    value: node,
    helpText: OptionType(StringType),
    baseline: OptionType(node),
    delta: OptionType(node),
    info: OptionType(UIComponentType),    // trigger for a ToggleTip beside the label
    indicator: OptionType(StatIndicatorType),
    // Visual
    style: OptionType(StatStyleType),
}),
```

**§0.3 paired-icon:** when `indicator.sentiment` is set and `indicator.icon` is absent, factory auto-injects the status-paired icon matching sentiment (positive → check; negative → triangle-exclamation; neutral → circle). Apps override with explicit `icon`.

**Migration:** existing `indicator: "up"` → `indicator: { direction: "up" }` (sentiment optional). Factory accepts both shapes during a single deprecation commit; after the breaking-change §0.7 window, only the struct form.

**Examples added:** (keep existing 3; add:)
- `statWithBaselineAndDelta` — mirrors shift-optimiser summary tile: label + mono value + baseline sub-line + delta pill with `direction: "down", sentiment: "positive"` (cost-is-better-when-down).
- `statInfoTooltip` — label has a ⓘ trigger opening a `ToggleTip`.

### 3.10 `Badge`, `Tag` — migrate flat shipped shape to main/style

Shipped `BadgeType` / `TagType` carry 20+ visual fields at top level — the 11-outlier set in the §0.10 allowlist. This plan moves those into `BadgeStyleType` / `TagStyleType`.

```ts
export const BadgeStyleType = StructType({
    // Visual presets
    variant: OptionType(StyleVariantType),
    colorPalette: OptionType(ColorSchemeType),
    size: OptionType(SizeType),
    // Shape / layout
    borderRadius: OptionType(StringType),
    borderWidth: OptionType(BorderWidthType),
    borderStyle: OptionType(BorderStyleType),
    borderColor: OptionType(StringType),
    overflow: OptionType(OverflowType),
    overflowX: OptionType(OverflowType),
    overflowY: OptionType(OverflowType),
    justifyContent: OptionType(JustifyContentType),
    alignItems: OptionType(AlignItemsType),
    width: OptionType(StringType),
    height: OptionType(StringType),
    minWidth: OptionType(StringType),
    minHeight: OptionType(StringType),
    maxWidth: OptionType(StringType),
    maxHeight: OptionType(StringType),
    padding: OptionType(PaddingType),
    margin: OptionType(MarginType),
    opacity: OptionType(FloatType),
    // Colour escape hatches
    color: OptionType(StringType),
    background: OptionType(StringType),
});

export const BadgeType = StructType({
    value: StringType,
    style: OptionType(BadgeStyleType),
});
```

`TagType` parallels — main = `{ label, closable?, onClose?, style }` where `closable` is state and `onClose` is behaviour. `TagStyleType` mirrors `BadgeStyleType` (with the same set of visual fields).

**Migration:** existing call sites like `Badge.Root(value, { variant: "solid", colorPalette: "blue", color: "red" })` become `Badge.Root(value, { style: { variant: "solid", colorPalette: "blue", color: "red" } })`. Factory may accept literal-union shorthands on style members for ergonomics (`style.variant: "solid"`).

### 3.11 Migration plan for BarSegment / BarList

Step 1 — land `SegmentedMeter` and `BarStrip` in `src/display/`.
Step 2 — migrate internal callers (matrix-cell examples, rotation-mix examples) to the new primitives.
Step 3 — delete `src/charts/bar-segment/` and `src/charts/bar-list/` and their tests / examples / renderers.
Step 4 — remove from `component.ts` `UIComponentType`.

Document this as a single-commit breaking change per §0.7.

## 4. Contract compliance

- §0.3 — `Stat.indicator` paired-icon auto-injection + escape.
- §0.2 — `Icon.label` decorative-vs-meaningful contract enforced in renderer.
- §0.10 — every display primitive uses the `{ ...content, style: OptionType(XxxStyleType) }` split. `check-contracts.ts` removes `Badge` / `Tag` / `Avatar` from the 11-outlier allowlist once this plan lands.
- Meter / SegmentedMeter / BarStrip are **pure Box composition** — no chart framework, no virtualisation, size by container. Verified by `grep` in CI that no `recharts` / `nivo` imports appear in these files.

## 5. Acceptance criteria

- [ ] `Stat` restructured `indicator` round-trips; default paired-icon works when sentiment set; apps without sentiment don't get a default icon.
- [ ] `SegmentedMeter` renders in a table cell without scrollbars / layout shift at widths down to 120 px.
- [ ] `BarStrip` renders 20-row lists without perf degradation (< 16 ms per layout on a mid-range laptop).
- [ ] `charts/bar-segment/` and `charts/bar-list/` deleted; no caller remains in `test/` / `examples/` / `App.tsx`.
- [ ] `Icon` without label → `aria-hidden="true"`; with label → `aria-label`.
- [ ] Every new primitive exports `X.Types.*` for consumer introspection.
