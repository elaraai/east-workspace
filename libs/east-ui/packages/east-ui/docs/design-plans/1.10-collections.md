# 1.10 — Collections (`Table`, `DataList`, `TreeView`, `Gantt`, `Planner`, + new `Matrix`, `Pagination`)

**Gaps-doc reference:** [`COMPONENT_AND_PATTERN_GAPS.md` §1.10](../COMPONENT_AND_PATTERN_GAPS.md).
**Scope:** Biggest primitive-plan. `Table` gains a large set of new fields (footer/colSpan/columnGroups/rowStatus/expandedContent/pagination/stickyFirstColumn/columnResize/selection model/virtualization/density) + full colour escape hatches. Colour escape hatches on `DataList`, `TreeView`. Gantt + Planner gain per-event escape hatches + root-level chrome colours + `rowStatus` callback. **Introduce `Matrix` primitive** (rowHeader/columnHeader UIComp slots, multi-overlay cells, brush selection, stickyFirstColumn, `CellAddressableComponent` interface). Add `Pagination` as a standalone primitive.

**Type-shape convention (README §Type-shape convention, 0-conventions §3.8):** rows / columns / items / frozen / footer / footerRows / columnGroups / selection / pagination / brushSelection / expandedContent / rowStatus / density + all callbacks (`onCellClick`, `onRowClick`, `onRowSelectionChange`, `onSortChange`, `onPageChange`, etc.) + wiring flags (`interactive`, `columnResize`, `virtualization`) stay on main. Visual presets (`variant`, `size`, `colorPalette`, `striped`, `stickyHeader`, `stickyFirstColumn`, `showColumnBorder`, `colorScale`) + dimensions + colour slots live in `style`. **Fix the shipped `TableStyleType` drafting error — it currently holds `onCellClick` / `onRowClick` / `onSortChange` / `onRowSelectionChange` and the `interactive` flag; these move OUT to main.**

**Out of scope:** `AssignmentBoard` / `RosterGrid` patterns (§2.5 plan) consume Matrix/Planner — their plans.

## 3. Per-entry design

### 3.1 `Table` — large widen

```ts
// Style struct — visual presets + dimensions + colour slots ONLY.
export const TableStyleType = StructType({
    // Visual presets
    variant: OptionType(TableVariantType),         // line | outline (canonical lives in collections/table/types.ts)
    size: OptionType(TableSizeType),
    colorPalette: OptionType(ColorSchemeType),
    striped: OptionType(BooleanType),              // cosmetic stripes
    stickyHeader: OptionType(BooleanType),         // layout-visual preset (alters scroll model)
    stickyFirstColumn: OptionType(BooleanType),    // layout-visual preset
    showColumnBorder: OptionType(BooleanType),     // visual preset
    // Dimensions
    height: OptionType(StringType),
    // Colour slots
    headerBackground: OptionType(StringType),
    headerColor: OptionType(StringType),
    borderColor: OptionType(StringType),
    zebraBackground: OptionType(StringType),
    hoverBackground: OptionType(StringType),
    selectedBackground: OptionType(StringType),
    selectedBorderColor: OptionType(StringType),
    footerBackground: OptionType(StringType),
});

// Table root (in component.ts):
Table: StructType({
    // Content
    rows: ArrayType(DictType(StringType, StructType({ value: LiteralValue, content: OptionType(node) }))),
    columns: ArrayType(StructType({ key, dataType, valueType, header, width, minWidth, maxWidth, render })),
    columnGroups: OptionType(ArrayType(StructType({ label: StringType, columnKeys: ArrayType(StringType) }))),
    footer: OptionType(DictType(StringType, StructType({ value, content, colSpan?: Integer, rowSpan?: Integer }))),
    footerRows: OptionType(ArrayType(DictType(...))),
    // Config / wiring flags
    frozen: ArrayType(StringType),
    interactive: OptionType(BooleanType),          // wiring: is the table row-clickable?
    columnResize: OptionType(BooleanType),
    virtualization: OptionType(BooleanType),
    density: OptionType(DensityType),              // inherited context, also per-component override
    // State / structured config
    rowStatus: OptionType(FunctionType([IntegerType], StatusTokenType)),   // per-row semantic token
    expandedContent: OptionType(FunctionType([IntegerType], UIComponentType)),
    pagination: OptionType(StructType({
        pageSize: IntegerType, page: IntegerType,
        onPageChange: FunctionType([IntegerType], NullType),
    })),
    selection: OptionType(StructType({
        mode: VariantType({ single: NullType, multiple: NullType, range: NullType }),
        selected: ArrayType(IntegerType),
        onChange: FunctionType([Array<Integer>], NullType),
    })),
    // Behaviour
    onCellClick: OptionType(FunctionType([TableCellClickEventType], NullType)),
    onCellDoubleClick: OptionType(FunctionType([TableCellClickEventType], NullType)),
    onRowClick: OptionType(FunctionType([TableRowClickEventType], NullType)),
    onRowDoubleClick: OptionType(FunctionType([TableRowClickEventType], NullType)),
    onRowSelectionChange: OptionType(FunctionType([TableRowSelectionEventType], NullType)),
    onSortChange: OptionType(FunctionType([TableSortEventType], NullType)),
    // Visual
    style: OptionType(TableStyleType),
}),
```

**Migration (§0.7 breaking):** shipped `TableStyleType` holds `interactive` + all `onCellClick`/`onRowClick`/`onSortChange`/`onRowSelectionChange` callbacks. Call sites passing these inside `style` must move them to the top-level options object. `check-contracts.ts` tracks the transition.

**`rowStatus` rationale:** returns a `StatusTokenType` (not a CSS colour). The renderer resolves to a background tint via the Chakra theme. Keeps the IR theme-agnostic and avoids 600k CSS string evaluations per second on virtualised tables.

**Cell `colSpan` / `rowSpan`:** on footer-row cells. Not on body rows for now — body spanning is complex and rarely needed.

**Virtualization:** lazy-loaded TanStack Virtual in the renderer. Tests must confirm that `virtualization: false` keeps existing behaviour.

**Examples added:**
- `tableFooterTotals` — totals row with `colSpan: 2` on the leading "Total · 3 weeks" cell, mirroring `shift-optimiser-mockup.html` lines ~1228–1238.
- `tableRowStatus` — at-risk / off-spec / on-track rows with `rowStatus` callback → `StatusTokenType`.
- `tableExpandedContent` — per-row detail expansion.
- `tablePagination` — 500-row dataset with 25-per-page pagination.
- `tableRangeSelection` — drag-select across a range of rows.
- `tableVirtualized` — 10k rows, virtualised.
- `tableColumnGroups` — two-row header with grouped columns.

### 3.5 `Matrix` (new)

```ts
export const MatrixCellOverlayKindType = VariantType({ icon: NullType, text: NullType, badge: NullType });
export const MatrixCellOverlayPositionType = VariantType({
    tl: NullType, tr: NullType, bl: NullType, br: NullType, center: NullType,
});

export const MatrixCellType = StructType({
    columnKey: StringType,
    segments: ArrayType(StructType({
        category: StringType,
        value: FloatType,        // 0..1
        color: OptionType(StringType),                 // per-segment data-level colour
    })),
    overlays: ArrayType(StructType({
        kind: MatrixCellOverlayKindType,
        content: UIComponentType,
        position: MatrixCellOverlayPositionType,
    })),
    emphasis: OptionType(ColorSchemeType),
    emphasisColor: OptionType(StringType),                 // per-cell data-level colour
    note: OptionType(StringType),
});

export const MatrixStyleType = StructType({
    stickyFirstColumn: OptionType(BooleanType),            // layout-visual preset
    colorScale: OptionType(ColorScaleType),                // visual scale preset
    // Colour slots
    background: OptionType(StringType),
    borderColor: OptionType(StringType),
    rowHeaderBackground: OptionType(StringType),
    columnHeaderBackground: OptionType(StringType),
    rowHeaderColor: OptionType(StringType),
    columnHeaderColor: OptionType(StringType),
    selectedCellBackground: OptionType(StringType),
    selectedCellBorderColor: OptionType(StringType),
    hoverCellBackground: OptionType(StringType),
});

export const MatrixType = StructType({
    // Content
    rows: ArrayType(StructType({
        key: StringType,
        header: UIComponentType,                           // rich row-header slot
        cells: ArrayType(MatrixCellType),
    })),
    columns: ArrayType(StructType({
        key: StringType,
        header: UIComponentType,                           // rich column-header slot
        subLabels: OptionType(ArrayType(StringType)),
    })),
    legend: OptionType(UIComponentType),
    // Structured config / behaviour
    brushSelection: OptionType(StructType({
        enabled: BooleanType,
        onChange: FunctionType([ArrayType(StructType({ row: StringType, column: StringType }))], NullType),
    })),
    // Visual
    style: OptionType(MatrixStyleType),
});
```

**`CellAddressableComponent` interface** (published for `AssignmentBoard.grid`): the renderer exposes a stable `cellId = "{rowKey}:{columnKey}"` addressing scheme; both `Matrix` and `Planner` implement it.

**Renderer:** CSS Grid `<div>` lattice. Sticky first column via `position: sticky; left: 0`. Brush selection via pointer-events and a floating selection rectangle; `onChange` fires on mouse-up.

**Examples** (5):
| Export | Description |
|---|---|
| `matrixCoverage` | Region × quarter matrix with numeric overlays (no segments) |
| `matrixWorkforceShift` | Area × day-of-week × shift-slot with per-cell `SegmentedMeter` + count overlay — mirrors Nestle briefing workforce grid (lines ~775–1275) but **as a preview; the production pattern is `Planner` with `slotMode: span`** (see §1.10 decision rule) |
| `matrixWithBrushSelect` | Brush-selectable cells across rows |
| `matrixRichRowHeader` | Row header is a Stack with area name + compliance chips (mirrors `.wf-area` cells + sidebar badges) |
| `matrixWithLegend` | Legend rail along the bottom |

## 4. Contract compliance

- §0.1 — Table respects parent `Card.state` fallbacks (when inside a Card with `state: loading`, Table renders SkeletonRows).
- §0.2 — Table row expansion is keyboard-operable (Enter/Space on the row); SR announces `aria-expanded`.
- §0.2 — Virtualized tables: renderer uses ARIA live-region announcements on scroll so SR users aren't lost. When `prefers-reduced-motion: reduce` OR an assistive-technology indicator is detected, virtualization auto-disables (falls back to full DOM render with CSS overflow).
