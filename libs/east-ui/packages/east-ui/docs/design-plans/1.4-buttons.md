# 1.4 — Buttons (`Button`, `IconButton`, `CopyButton`, + new `CloseButton`, `Toggle`, `ButtonGroup`)

**Gaps-doc reference:** [`COMPONENT_AND_PATTERN_GAPS.md` §1.4](../COMPONENT_AND_PATTERN_GAPS.md).
**Scope:** Widen `Button` / `IconButton` / `CopyButton` with rich labels, icons, loading-icon, colour escape hatches; enforce `IconButton.label` (aria-label) as non-optional; add `CloseButton`, `Toggle`, `ButtonGroup` primitives. Apply the Type-shape convention (README §Type-shape convention, 0-conventions §3.8): content (`label`, `startIcon`, `endIcon`, `loadingText`, `loadingIcon`, copy `value`) + state (`loading`, `disabled`, `pressed`) + config (`timeout`) + behaviour (`onClick`, `onChange`) on main; visual presets (`variant`, `colorPalette`, `size`) + colour escape hatches inside `style: OptionType(XxxStyleType)`. **Shipped ButtonStyleType / CopyButtonStyleType mix state + behaviour + visual today — this plan cleans them by moving `loading` / `disabled` / `onClick` / `timeout` OUT to main.**
**Out of scope:** `commitStrength` on `ActionCard.primary` / `DecisionBar.primary` — those live in §2.3 / §2.5 plans.

## 3. Per-entry design

### 3.1 `Button` (widen)

```ts
export const ButtonStyleType = StructType({
    // Visual presets
    variant: OptionType(ButtonVariantType),        // solid | subtle | outline | ghost | plain
    colorPalette: OptionType(ColorSchemeType),
    size: OptionType(SizeType),
    // Colour escape hatches
    color: OptionType(StringType),                 // label + icon tint
    background: OptionType(StringType),
    borderColor: OptionType(StringType),
    hoverBackground: OptionType(StringType),
});

export const ButtonType = StructType({
    // Content / identity
    label: UIComponentType,                        // was StringType — string coerced at factory
    startIcon: OptionType(IconType),
    endIcon: OptionType(IconType),
    loadingText: OptionType(StringType),
    loadingIcon: OptionType(IconType),
    // State
    loading: OptionType(BooleanType),
    disabled: OptionType(BooleanType),
    // Behaviour
    onClick: OptionType(FunctionType([], NullType)),
    // Visual
    style: OptionType(ButtonStyleType),
});
```

**Migration:** shipped `ButtonStyleType` has `variant`, `colorPalette`, `size`, `loading`, `disabled`, `onClick` all in it. New split moves `loading`/`disabled`/`onClick` to the main struct and keeps only the visual presets in the style struct. Breaking — call sites using `style: { loading: ..., onClick: ... }` move them out to the main options object.

**Examples added:**
- `buttonWithIcons` — start + end icons.
- `buttonLoading` — loading state with `loadingText` + `loadingIcon: faSpinner`.
- `buttonRichLabel` — label is `Stack.HStack([Text.Root("Accept"), Text.Root("→ log to MES", { color: "fg.muted" })])` — mirrors `Nestle CEO Briefing v3.html` line ~627.
- `buttonGhost` — ghost variant, full colour escape hatches.
- `buttonPlain` — plain variant (unadorned).

### 3.2 `IconButton`

Require `label: StringType` non-optional (aria-label). Renderer maps it to `aria-label`.

```ts
export const IconButtonStyleType = StructType({
    variant: OptionType(ButtonVariantType),
    colorPalette: OptionType(ColorSchemeType),
    size: OptionType(SizeType),
    // Colour escape hatches
    color: OptionType(StringType),                 // icon tint
    background: OptionType(StringType),
    borderColor: OptionType(StringType),
    hoverBackground: OptionType(StringType),
});

export const IconButtonType = StructType({
    // Content / identity
    prefix: StringType,                            // FA icon prefix
    name: StringType,                              // FA icon name
    label: StringType,                             // REQUIRED aria-label
    loadingIcon: OptionType(IconType),
    // State
    loading: OptionType(BooleanType),
    disabled: OptionType(BooleanType),
    // Behaviour
    onClick: OptionType(FunctionType([], NullType)),
    // Visual
    style: OptionType(IconButtonStyleType),
});
```

**Test:** a compile-time assertion that `IconButton.Root({ prefix, name })` (no label) fails type-checking.

### 3.3 `CopyButton`

Main = `{ value, label?, timeout?, disabled?, style }`. `timeout` (how long the "Copied!" state shows) is config; `value` (the string to copy) is content. Visual presets and colour slots in style, including `successColor` for the "Copied!" swap.

```ts
export const CopyButtonStyleType = StructType({
    variant: OptionType(CopyButtonVariantType),
    colorPalette: OptionType(ColorSchemeType),
    size: OptionType(SizeType),
    // Colour escape hatches
    color: OptionType(StringType),
    background: OptionType(StringType),
    borderColor: OptionType(StringType),
    hoverBackground: OptionType(StringType),
    successColor: OptionType(StringType),          // "Copied!" confirmation tint
});

export const CopyButtonType = StructType({
    value: StringType,                             // content — string to copy
    label: OptionType(StringType),
    timeout: OptionType(StringType),               // config — "Copied!" duration
    disabled: OptionType(BooleanType),
    style: OptionType(CopyButtonStyleType),
});
```

**Migration:** shipped `CopyButtonStyleType` has `disabled` + `timeout` + visual presets. New split moves `disabled` + `timeout` to the main struct; style holds only visual fields.

**Example:** `copyButtonBranded` — the copy button used in a code-block header with brand accent.

### 3.4 `CloseButton` (new)

```ts
export const CloseButtonStyleType = StructType({
    variant: OptionType(ButtonVariantType),
    size: OptionType(SizeType),
    color: OptionType(StringType),
    background: OptionType(StringType),
    borderColor: OptionType(StringType),
    hoverBackground: OptionType(StringType),
});

export const CloseButtonType = StructType({
    label: OptionType(StringType),                 // aria-label, default "Close"
    disabled: OptionType(BooleanType),
    onClick: OptionType(FunctionType([], NullType)),
    style: OptionType(CloseButtonStyleType),
});
```

**Renderer:** Chakra `<CloseButton />`. Used by Tag (closable), Dialog, Drawer, Alert, Banner, Toast dismissers.

**Examples** (2): `closeButtonBasic`, `closeButtonInDialog`.

### 3.5 `Toggle` (new)

Distinct from Switch — a two-state button often sitting in a toolbar. Main carries content (`label`, `icon`), state (`pressed`, `disabled`), and behaviour (`onChange`). Style holds visual presets + colour slots.

```ts
export const ToggleStyleType = StructType({
    variant: OptionType(ButtonVariantType),
    size: OptionType(SizeType),
    // Colour escape hatches
    color: OptionType(StringType),
    background: OptionType(StringType),
    borderColor: OptionType(StringType),
    pressedBackground: OptionType(StringType),
    pressedColor: OptionType(StringType),
});

export const ToggleType = StructType({
    // Content
    label: UIComponentType,
    icon: OptionType(IconType),
    // State
    pressed: BooleanType,
    disabled: OptionType(BooleanType),
    // Behaviour
    onChange: OptionType(FunctionType([BooleanType], NullType)),
    // Visual
    style: OptionType(ToggleStyleType),
});
```

**Renderer:** Chakra `<Toggle />` — with `aria-pressed` mirroring state.

**Examples** (3): `toggleGridlines` ("Show gridlines"), `toggleLockColumns`, `toggleAutoRefresh`.

### 3.6 `ButtonGroup` (new)

Main = `{ buttons, style }`. `attached` is a visual-layout preset (it determines whether buttons render with shared borders), so it moves to style alongside the other visual presets.

```ts
export const ButtonGroupStyleType = StructType({
    attached: OptionType(BooleanType),             // visual-layout preset
    size: OptionType(SizeType),
    variant: OptionType(ButtonVariantType),
    colorPalette: OptionType(ColorSchemeType),
    borderColor: OptionType(StringType),           // shared border between attached buttons
});

// Main variant (inline in component.ts — carries recursive button children):
ButtonGroup: StructType({
    buttons: ArrayType(node),                      // each must be a Button / IconButton / Toggle / CloseButton
    style: OptionType(ButtonGroupStyleType),
});
```

**Factory:** `ButtonGroup.Root(buttons, { style? })`.

**Renderer:** Chakra `<Group>` or `<ButtonGroup>` (whichever Chakra v3 exports).

**Examples** (3):
| Export | Description |
|---|---|
| `buttonGroupPrevNext` | `[◀ Prev] [Next ▶]` attached |
| `buttonGroupTimescale` | `[1d][1w][1m][3m][1y]` — a toolbar for `TimeScaleControl` |
| `buttonGroupSplit` | Mixed: Button + IconButton (overflow menu trigger) |

## 4. Contract compliance

- §0.2 — `IconButton.label` required; Chakra's default `aria-label` is insufficient. Assert in `a11y-axe.spec.tsx`.
- §0.3 — n/a (Buttons aren't semantic status by default; if `colorPalette` is a semantic token, the app is responsible for icon + label semantics).
- §0.10 — every button primitive follows the main/style split. `check-contracts.ts` removes `ButtonStyleType` / `CopyButtonStyleType` from its "style-struct allowlist" once `loading` / `disabled` / `onClick` / `timeout` have been moved out.
