§ 2.6

Trust

Anchor · Decision.Journal (in §2.3 Decide)

The connective tissue. Every decision the operator takes, every model output that gets cited, every roster that gets published — they all carry provenance. Trust mode is where the system answers who, when, on what basis, with what assumptions. Without it, every other mode is just opinion.

Trust contract

  1. Every output is stamped. A Trust.Stamp shows model version, run time, input hash, and confidence band. No headless numbers.
  2. Every change is journaled. A Decision.Journal entry (pattern in §2.3 Decide) captures the actor, the rationale, the diff, and the run it was made against. Append-only.
  3. Staleness, partiality, and drift are surfaced — not hidden. Banners fire when a source goes stale, a feed drops, or the world has changed since the operator last looked.
  4. Communication is part of the system. Handoffs, message-stubs, and reviewer comments live in the same surface as the decision.
  5. Permission is positive. If an operator can't take an action, the gate explains why and routes to whomever can.

Trust.*

Provenance, projected onto four surface densities. The Chip fits next to a number, the Footer fits across the bottom of a card, the Stamp fits inside an expansion, and the AuditTrail fits when forensic work is the whole job. One Provenance object, four projections — a Chip can always expand to a Stamp; a Stamp links to its Trail.

Compact provenance chip. Shows model version + freshness + status dot. Inline anywhere a model output appears. Hover/click reveals the full Trust.Stamp.

Banner.*

Banners answer one question for the operator before they act: what shifted, what's degraded, what's aged out. Three voices — ChangeSinceLastVisit, Partial, Stale — sharing one slot at the top of every surface. One banner shows at a time; if multiple trigger, they stack (max three visible, rest behind a count). Banners describe state; the operator decides what to do.

Banner.ChangeSinceLastVisit

Fires when the world has materially changed since the operator's last session. Not "what's new on the dashboard" — "what shifted out from under you while you were away".

⏵ 3 things changed since you last looked (Mon)
  • Forecast revised +14% · driver: regional event added view
  • Cho's availability changed · sick-leave Wed–Fri view
  • SLA target updated · 0.92 → 0.95 by Singh view
 dismiss all
Banner.Partial

Fires when one of the model's required inputs is missing or degraded. Recommendations still surface but flagged as partial — the gap is named.

◐ Partial run · operator-preferences offline — model fell back to last-known snapshot from 4 days ago. 2 of 7 sources · confidence reduced by 0.08 · cohort sample halved sources →·re-run when restored
Banner.Stale

Fires when a source feeding the current view has gone past its freshness threshold. Doesn't block — but the operator must see it before they act.
