Collections.Library

A draggable palette of things that get assigned into Collections.Roster (or any grid surface): people, assets, vehicles, rooms. Each item carries a primary identity plus configurable secondary dimensions (role, skills, hours, certifications, location) that are filterable, groupable, and visible on the card. Drag a card onto a Roster cell to assign; ⌥-drag to duplicate; cards dim when filtered out instead of disappearing so the user keeps a stable mental map.
