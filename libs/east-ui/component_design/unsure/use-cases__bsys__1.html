Reading the matrix: Forward → is the canonical happy path arrow drawn around the outside of the loop diagram. Jumps ↺ are the back-edges drawn as dashed inner arrows — three of them: Probe → Understand when a tweak settles and the briefing re-renders, Compare → Commit when the operator skips re-judgement because the load-bearing inputs were already attested, Modify → Probe when Commit.Bar's Modify expands the briefing in place. Judge has no jump out — it gates Commit and is never skipped. Communicate's forward arrow closes the loop (↻) back to Triage for the next case.
