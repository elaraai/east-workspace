Collections.Line

A value-over-axis editor — a sequence of (axis-position, value) points connected by a polyline, each point draggable. Use when an input or lever is meaningfully axis-shaped (time, distance, scenario stage) and a single end-state value would hide the path. Optional uncertainty band shades around the line; the leftmost handle can be locked when it represents "today" or another fixed observation.
