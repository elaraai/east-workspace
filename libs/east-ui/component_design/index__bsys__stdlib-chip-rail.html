Rules: A chip rail is one horizontal run of .chips — filters, applied scope, segment toggles — wrapping only when the container forces it. The labeled mode stacks a centered .cr-label (mono · uppercase · ink-4) above each chip when the value alone is ambiguous — a bare SE needs its Region caption; region · SE in the plain rail does not. Density is a single knob — compact for table eyebrows and dense toolbars, comfortable as the default, large for touch and focused pickers. It scales pad, font, gap, radius and label-gap together; never mix densities inside one rail. Active = .brand; the empty slot is always a trailing .dashed add. Keep one rail to one dimension family — don't blend scope chips and action chips on the same line.
