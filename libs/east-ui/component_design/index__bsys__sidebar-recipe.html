Scope
A flat list of top-level navigation entries in a fixed order — the operator's mental model of the app at rest.

Item types — link (icon + label, default), group header (section eyebrow, non-interactive), divider (1 px rule, 10 px margin), nested sub-item (indented 36 px, em-dash prefix, drops the uppercase styling).

Forbidden: deeper than two levels of nesting · notifications · avatar · settings link · anything that isn't a top-level mode, a sub-item of one, or a scope.
States: Expanded (default) — 240 px wide, full labels. Collapsed — 56 px icon rail, label moves to a hover tooltip after 400 ms delay. Toggle via the chevron in the top-right of the panel, or [. The state is persisted to localStorage per user, never per route. Below 768 px the sidebar is always collapsed and the toggle is hidden; below 560 px it becomes an overlay (see below).
Layout: Push, not overlay on desktop — the sidebar shares the viewport with Main; toggling collapse animates the Main width over --dur-base. Main content reflows; never clipped, never scrolled horizontally. Overlay only on mobile (≤ 560 px) — full-height sheet from the left, scrim over Main, dismissed on backdrop tap or Esc. Sticky to viewport top; vertical overflow inside the sidebar scrolls independently of Main when the list is long. Scope selector and any "pinned" group stay anchored to the bottom of the sidebar; the middle list region is the scrolling part.
Logo region: The wordmark sits in a fixed-height region pinned to the top of the sidebar — the region is specified, not the wordmark glyph inside it. This keeps every screen's vertical rhythm consistent regardless of wordmark width or whether an app-mark is present. Region height — 64 px expanded · 56 px collapsed. Both align with the Header row above so the sidebar top edge meets the header's bottom rule cleanly. Internal padding — 16 px left / right · vertically centred. The wordmark anchors to the left padding edge; collapsed state centres the app-mark in the column. Bottom padding — 12 px rule-free gap between the region's bottom edge and the first item below it (section eyebrow or first link). No bottom rule under the logo region — visual separation comes from the gap, not a divider. Forbidden inside the region: badges, version stamps, environment tags, search affordances, toggles. The region is identity, not chrome — anything else belongs in the Header.
Dimensions: Width 240 px expanded · 56 px collapsed · right rule 1 px rule · background paper-2 · item height 36 px · active state · brand-tint fill 4 px radius with 8 px side inset (pill) · icon column 16 px, gap to label 10 px. Item label mono 12 px / 600 / 0.12 em uppercase · sub-item 11 px / 500 / 0.08 em, normal case · section eyebrow mono 9.5 px / 600 / 0.18 em in ink-4. Top of sidebar aligns with the bottom of the Header rule; bottom hugs the viewport floor.
