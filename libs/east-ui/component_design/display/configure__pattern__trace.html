Collections.Trace read-only projection of Planner

The inline, read-only twin of Collections.Planner. Same axis grammar — rows × ordered steps on a datetime, numeric or ordinal axis, split by the same 1px brand-d now-line — but each step renders a single heat-mapped scalar instead of a draggable event. Each track (a measure) runs measured past → predicted future left-to-right: past steps are solid (the committed read), future steps are hatched + italic (the proposed read). No events, no DnD, no commit ownership — it is a glance, sized to live inside a table cell. Density is variable: compact · comfortable · large.

Reading a Trace
Track — one measure (Bé, Temp, pH), one row. A short stub labels it on the left.
Step — one position on the axis. Fill encodes the value on the chosen scale; the number renders inside at comfortable / large density, and is dropped at compact.
Now-line — a 2px brand-dd rule with a 1px paper moat, dividing measured past from predicted future with strong contrast against the heat fills. Hover the line for the exact position. Per-track placement via stepsPast.
Past vs future — past steps are solid heat fills (measured / committed read); future steps are lighter-tinted with a dashed heat-coloured edge and italic value (predicted / proposed read). The grammar is borrowed wholesale from Planner — solid box vs dashed ghost — so the two never contradict each other.
Configuration
PropValuesEffect
densitycompact · comfortable · largeStep size + whether the in-step value and axis ruler render. Compact is table-cell sized; large is a standalone panel.
scalebrand · diverge · categoricalColour encoding. brand = sequential teal; diverge = teal↔terracotta centred on each track's midpoint; categorical = one hue per track, value mapped to intensity.
axisdatetime · numeric · ordinalThe step ordering. One axis type per Trace — same rule as Planner. Labels surface in the ruler (large) and in step tooltips.
stepsPastintHow many leading steps are measured. The rest are predicted; the now-line is drawn at the boundary. Set per track.
futureghost · hatch · fadeHow the predicted zone is distinguished. ghost (default) = lighter fill + dashed heat edge, mirroring .evt-proposed; hatch adds 45° lines; fade drops the edge and lowers opacity.

Trace is not a Planner. It shares the axis grammar and the now-line, but it is read-only by construction — no events, no committed/proposed state machine, no drag-and-drop, no Commit.Bar ownership. If a surface needs to edit the schedule, it is a Planner; if it only needs to show a measured-and-forecast trajectory at a glance, it is a Trace. One value per step. A step holds a single scalar. Multiple measures = multiple tracks, never multiple values stacked in one step. For two scenarios over one measure, render two tracks (e.g. Bé · actual, Bé · model). Naming. Recommended Collections.Trace — "trace" reads as a recorded-plus-forecast signal and sits in the same namespace as Planner / Roster / Gantt. Alternates considered: .Track, .Strip, .Sparkgrid. Variants: Collections.Trace.Inline — the compact, value-less, table-cell form (the hero). Collections.Trace.Panel — the large form with axis ruler and per-step values.
