Dimensions: Rail — width clamp(280px, 34%, 380px) · rail–stage gap 28px · prose max 46ch. Step runway — stepLength: compact 36vh · default 52vh · long 72vh; first step starts active at load, last step gets +20vh tail so it can complete before the story scrolls out. Trigger line — a step activates when its block crosses 38% from the viewport top; within-step progress ∈ [0,1] is the block's travel through that line. Stage — sticky top: 16px (+ chrome height when Story.Progress sits above) · height stageHeight (default 420px) · unchromed slot, keyframes bring their own framing · the stage never resizes between keyframes. Spine — 2px rule at rail-left; node 10px, rule-strong ring → brand-d ring when visited → filled when active.
Layouts: rail-left (default) — prose left, stage right; reading order matches scan order. rail-right — mirror; for pages whose surrounding chrome already sits left. stacked — forced under 720px: stage compresses to min(stageHeight, 280px), sticks to the top, prose scrolls beneath it full-width. There is no overlay layout.
