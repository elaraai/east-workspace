Collections.Gantt

A configuration of Collections.Planner.Span — axis = datetime, events are multi-slot spans with start & end, plus the project-planning affordances Gantt-style consumers need: dependency arrows (finish-to-start, start-to-start, with slip detection), milestones (zero-duration point markers as diamonds), critical path overlay, and a "now" line distinguishing committed past from proposed future. Same event-state grammar (committed / proposed / rejected) and the same five typed column kinds as Planner; the difference from Planner.Point is shape (span vs point), not scaffolding.

Drag & drop Supports the full Planner grammar — add (drop a task from a sibling Library), move (drag a bar body to reschedule), remove (drag a bar off the surface), resize (drag a bar edge to change duration). Only proposed bars are draggable; committed bars are read-only and resize-locked. Snaps to dragStep; dependency arrows turn amber-dashed when a successor slips behind its predecessor.
