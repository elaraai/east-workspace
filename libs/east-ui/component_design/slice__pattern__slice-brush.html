Slice.Brush

The continuous-range narrowing — drag a window across an x-axis overview to slice to a sub-range. The visual, direct-manipulation cousin of Slice.Range: where Range is a pill + preset list, Brush is a draggable selection over a sparkbar signal, so you see the distribution you're cutting into. Outside the window dims; two handles resize, the body drags. Optionally it reads out values over the selected range.

Values mode (the readout): range resolves to an x-range only; summary adds a live Σ / avg / n over the brushed buckets; values labels each selected bucket with its value. The readout recomputes on every drag — it's the answer to "what's in this window?". Pairs with a chart. Brush is an overview-and-detail control: the brushed range drives a larger chart above it. It owns the x-slice the same way Range does, and emits the same resolved-range contract. Snap: handles snap to bucket boundaries by default (snap=\"bucket\"); continuous snap is opt-in for dense signals. Density: compact (≈28px track, for an eyebrow or filter rail) · comfortable (default, under a chart) · large (≈72px, a standalone overview-and-detail panel). Overflow: n/a — the signal always fits the track width; bucket count is capped so bars stay ≥ 3px.
